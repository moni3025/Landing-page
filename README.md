# 🌐 My First Landing Page

This is my first landing page project, created as part of my journey into frontend web development.

The project focuses on building a simple, clean, and responsive webpage using HTML and CSS. It helped me understand the fundamentals of webpage structure, styling, layout, and responsive design.

## ✨ Features

* Clean and simple user interface.
* Navigation bar with multiple links.
* Hero section with heading, description, and image.
* Call-to-action button.
* Feature section with descriptive content.
* Responsive layout for desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

* **HTML5** – For webpage structure.
* **CSS3** – For styling and layout.
* **Flexbox** – For arranging elements.
* **Media Queries** – For responsive design.

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.
